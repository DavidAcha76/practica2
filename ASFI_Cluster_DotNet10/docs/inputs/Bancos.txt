Endpoints por cada API:

http
GET  /                         # Información general y lista de rutas
GET  /api/banco/info           # Banco, algoritmo y motor de BD
GET  /api/cuentas              # Lista de cuentas cifradas
GET  /api/cuentas/{id}         # Cuenta cifrada por RecordId
POST /api/cuentas              # Crea y cifra una cuenta
POST /api/cuentas/seed-demo    # Inserta 3 cuentas cifradas de demostración


Ejemplo para Banco Unión:

http
GET  http://localhost:5101/api/banco/info
POST http://localhost:5101/api/cuentas/seed-demo
GET  http://localhost:5101/api/cuentas
GET  http://localhost:5101/api/cuentas/{recordId}
